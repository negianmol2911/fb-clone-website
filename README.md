# 🌐 fb-clone-website

Welcome to my Facebook Website Clone! 

This project is a simplified front-end clone of the classic Facebook user interface. I primarily built this project as a hands-on exercise while following a comprehensive Git and version control tutorial. 

## 📖 About the Project

The main goal of this repository isn't to build a fully functional social media platform, but rather to practice translating a complex design into code and, most importantly, to understand the Git workflow. Throughout the development of this clone, I focused on tracking changes, making regular commits, and managing a repository effectively.

## ✨ Features (Mockup)

*   **UI Layout:** A structural layout mirroring the familiar Facebook login and feed interfaces.
*   **Static Front-End:** Built to understand page structure, styling, and element positioning.
*   **Version Control History:** A practical demonstration of fundamental Git operations from initialization to final commits.

## 🛠️ What I Learned

Building this clone was a great way to solidify my version control skills alongside web development. Key takeaways include:
*   Initializing and configuring local Git repositories.
*   Staging and committing changes with descriptive messages.
*   Understanding how to track project history and revert changes if necessary.
*   Structuring the layout of a standard web application.
